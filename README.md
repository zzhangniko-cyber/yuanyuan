> 深圳 1021 个小区步行实测 —— 从家门口出发，15 分钟医疗圈如何真正走进生活？

## 本地预览

直接双击 `index.html` 即可。

若想更接近线上环境（推荐），在本目录下起一个静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（建议命名为 `15min-medical-circle`）。
2. 把本压缩包内的**全部文件和文件夹**上传到仓库根目录，务必保留 `assets/`、`img/` 的目录层级（拖拽整个文件夹上传，不要只传 `index.html`）。
3. 进入仓库 `Settings` → 左侧 `Pages` → `Source` 选 **Deploy from a branch** → 分支选 `main`、目录选 **/(root)** → `Save`。
4. 等 1–2 分钟刷新该页面，拿到访问地址：`https://<你的用户名>.github.io/<仓库名>/`。

补充说明：

- 纯静态站点，**不需要任何构建步骤**，也不需要 `package.json`。
- 用「网页上传」方式时，以点开头的 `.nojekyll` 可能被忽略。若上传后少了它，可在仓库里手动新建一个名为 `.nojekyll` 的空文件（内容留空即可）。
- 图片与页面里含中文文件名，GitHub Pages 会做 URL 编码，正常可访问；若个别图片出现 404，可把文件名统一改为 `img/fig-1-1.jpg` 这类纯英文名，并同步修改 `index.html` 中的引用。
- 站内全部路径均为**相对路径**，更换仓库名或迁到其他托管都不需要改代码。

## 上线后建议补一步（分享卡片）

`<head>` 里的分享图目前是相对路径：

```html
<meta property="og:image" content="img/hero_pastel.jpg">
```

微信、微博、Twitter 等平台抓取分享卡片时**要求绝对 URL**，建议拿到正式地址后改为：

```html
<meta property="og:image" content="https://<用户名>.github.io/<仓库名>/img/hero_pastel.jpg">
<meta property="og:url"   content="https://<用户名>.github.io/<仓库名>/">
```

## 数据与口径

所有图表数据内嵌在 `assets/charts.js` 中（含深圳分区 GeoJSON，同样内联，不请求外部接口），每张图下方都标注了**数据来源 / 样本量 / 时间 / 口径**。几条关键红线：

- 全国基层诊疗占比采用 2025 年统计公报口径 **53.1%**，此前吹风会口径 **52.6%** 仅作对照，两者不混用。
- 图 7 中的 **65%** 出自国办发〔2015〕70 号附件，属**试点城市考核标准**，引用须写「试点」，不是全国统一目标。
- 图 1（基层诊疗量占比）与图 7（距 65% 的绝对缺口）口径不同，**互补，不作并列或相减**。
- 官方「90% 以上居民 15 分钟可达」与本次深圳 1021 小区实测的 **85.3%** 属不同样本、不同口径，**不作直接相减**。
- 945 家社康中 **177 家**缺少可用的营业时间字段（18.7%），另有 **171 个小区**无法确认最近社康的营业时间；两组数字统计单位不同，不可相加。
- 夜间可达率是保守下限（0.8% 的夜间基线来自 24 小时值班站及营业时间缺失机构）；「城市人作息」曲线为示意，非实测。
- 各区不可达人口由小区不可达率 × 常住人口折算估计，非逐户统计。

完整说明见页面末尾「数据溯源」章节。
